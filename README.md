# Dandiyaa

A privacy-first, independent student social experience for Dandiya night.

## Core flow

- 18+ voluntary registration
- College selection: PCCOE Nigdi or D. Y. Patil Akurdi
- College-separated matchmaking pools
- Senior / junior / same-year / any preference treated as a preference, not a guarantee
- Admin-controlled registration countdown
- Match reveal after the event closes
- Mutual acceptance before optional contact/social details are revealed
- Reject / rematch / block / report flows
- Supabase Postgres + Auth + RLS
- Next.js App Router, deployable to Vercel

> **Non-affiliation notice:** Dandiyaa is an independent student-run/social experience. It is not an official program, event, service, sponsorship, or endorsement of PCCOE Nigdi or D. Y. Patil Akurdi unless expressly authorized.

Official college logos, crests, and protected branding are intentionally not used.
